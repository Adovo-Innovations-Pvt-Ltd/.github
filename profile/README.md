# Adovo

Adovo is a founder-led team in Kochi, India. We build enterprise Adobe Experience Cloud solutions, connect fragmented data, and make measurement useful across systems.

Our work covers Adobe Experience Manager (AEM), Adobe Analytics, data integration, reporting, and applied AI for defined workflows.

## What we work on

- [Adobe Experience Cloud](https://www.adovo.ai/services/adobe): AEM delivery, connected experiences, measurement, and personalization.
- [Data and measurement](https://www.adovo.ai/services/data): data flows, shared definitions, and reporting that teams can act on.
- [Applied AI](https://www.adovo.ai/services/ai): bounded use cases built around clear data, permissions, and evaluation.
